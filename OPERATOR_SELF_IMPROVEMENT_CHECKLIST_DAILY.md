# Daily 60-Second Operator Checklist

Use before starting work and before declaring done.

## Start (30s)
- Objective (one line):
- Scope limit (one line):
- Highest risk:
- Verify with (exact command/artifact):

## During (20s)
- FACTS only from evidence
- INFERENCE clearly labeled
- ACTION = one remediation only

## Stop Conditions (instant escalate)
- Wrong/unknown repo or path
- Unexpected extra modified files
- Auth/credential mismatch
- Freeze-window conflict
- Critical confidence < 0.7

## Done Gate (10s)
- Proof attached (output/diff/status/test)
- Result stated in one line
- Next step (only if needed)

## KPI Tick (optional)
- First-pass success: Y/N
- Rework needed: 0/1+
- Time to verified resolution: __ min

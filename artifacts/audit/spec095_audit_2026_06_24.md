## Spec 095 Resolution

The conflation described in Spec 095 was:
- Old tools measured IC on `composite_score` (full ~300-ticker universe)
- Ranker operates on `final_score` (eligible ~60-ticker cohort only)
- Claiming composite_score IC as "ranker IC" overstates coverage and mixes two different pools

**Current state:**
- `measure_final_score_ic_spec100.py` uses `final_score` on the correct cohort ✓
- `run_true_ranker_ic.py` is a dead stub — never ran, never produced output ✓
- No other tool makes ranker IC claims using composite_score ✓

**Recommendation:** Close Spec 095. The one remaining action is deprecating
`run_true_ranker_ic.py` to prevent future confusion.

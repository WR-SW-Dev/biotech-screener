# Biotech Catalyst Probability Drills

### Probability Drill 1:
**Scenario:** A biotech company has a Phase 2 trial for a new drug targeting a rare disease with an interim analysis showing a 30% response rate.
**Question:** If the true response rate is actually 50%, what is the probability that the interim data would show a 30% or lower response rate?
**Answer:** ~17%
**Key Insight:** Interim data can be misleading; it's crucial to consider the base rate of success.

### Probability Drill 2:
**Scenario:** A drug shows promising results in Phase 2 with an 80% response rate. The company decides to move to Phase 3.
**Question:** If the true efficacy is actually 50%, what is the probability that the Phase 3 trial will show a statistically significant result?
**Answer:** ~16%
**Key Insight:** Moving from Phase 2 to Phase 3 based on interim data can lead to false positives.

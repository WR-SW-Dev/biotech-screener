### openclaw-data-pipeline-debug (4 new classes)

**Class M — Stale price from yfinance rate-limit fallback**
- **Signature:** close_price stale for multiple days, IC measurements return NaN or 0.0
- **Root cause:** yfinance falls back to cached data on rate-limit instead of raising error
- **Diagnostic:** Check `collected_at` timestamp in market_data.json
- **Resolution:** Patch from price_history.csv, add pre-patch step in run_daily_production.py
- **Confirmed:** 2026-06-24 (commits fe0d8e66, be47e268)

**Class N — yfinance date format silent rejection**
- **Signature:** yfinance API calls return empty results without error
- **Root cause:** datetime.isoformat() includes time component, yfinance rejects silently
- **Diagnostic:** Check if yfinance calls use isoformat() vs strftime("%Y-%m-%d")
- **Resolution:** Use strftime("%Y-%m-%d") for date-only strings
- **Confirmed:** 2026-06-24 (commit 411cbe40)

**Class O — Universe contamination from delisted tickers**
- **Signature:** Screening results include delisted tickers, coverage ratios inflated
- **Root cause:** Inconsistent filtering of status=delisted tickers across pipeline stages
- **Diagnostic:** Check if all universe consumers filter status!=delisted
- **Resolution:** Apply filter immediately after loading universe, before downstream computation
- **Confirmed:** 2026-06-24 (commit 974a67b9)

**Class P — LangGraph artifact schema drift**
